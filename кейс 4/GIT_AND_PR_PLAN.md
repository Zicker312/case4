# Git / Pull Request план

Реальные Pull Request нельзя честно создать внутри архива, поэтому перед сдачей их нужно сделать в своём GitHub/GitLab.

Рекомендуемые ветки:

- `feature/auth`
- `feature/docker-nginx`
- `feature/monitoring`
- `feature/tests-docs`

Примеры атомарных коммитов:

- `feat(auth): add jwt and refresh sessions`
- `feat(deploy): add docker compose and nginx`
- `feat(monitoring): add grafana dashboard and alerts`
- `test(api): add auth and policy checks`
- `docs(readme): add deployment and operations guide`
